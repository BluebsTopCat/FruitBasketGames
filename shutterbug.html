Shutterbug is a follow-up project to my 2021 game Viewfinder, a short experience about taking photos in the woods. Shutterbug would still be about photography, but specifically about cryptids in the Quebec wilderness.

Development is currently on pause, but I've created a variety of visual and auditory work on the project that you can browse through here!

Visuals

Visually, I wanted the project to be evocative of games like Firewatch, similar to FDR tourism posters and with painterly touches. Unity's standard lighting system isn't good for this, so I created my own shader set in Amplify Shader Editor that puts an emphasis on color, and combined it with brushstroke-based textures and procedural gradients for things like the sky.

As part of the project, I also created a full time-of-day system with cloud coverage, stars, and gradients that apply over the full map. It’s an impressive effect that I’m certainly going to take to use elsewhere. you can see it in the music video after this!
